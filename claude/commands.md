The video outlines several essential commands to optimize your workflow with *Claude Code*. Typing a forward slash (/) in any session will pull up the full menu, but these are the most impactful ones:

* **/clear**: Wipes the current conversation context (2:27). This is ideal for starting a fresh task without carrying over stale information.
* **/compact**: Compresses the conversation history into a summary (2:48), which helps maintain focus when the context window starts to get full.
* **/review**: Performs a structured review of your uncommitted changes (3:18) before you open a pull request.
* **/permissions**: Allows you to pre-authorize repetitive actions (3:27), such as reading files or running tests, to prevent constant interruptions.
* **/ptw**: Used for quick side questions (4:39) without polluting your main conversation history.
* **/reind**: Functions like an undo button (5:14), letting you revert to an earlier checkpoint in the session.

**Pro-tip:** You can also use **Plan Mode** by pressing **Shift + Tab** twice (5:22). In this mode, *Claude* can read and search your codebase but is restricted from making any edits, making it perfect for exploring and planning before writing code.
